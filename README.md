# Blockchain-filter-windows-connection-demo
Software for Windows to connect to the blockchain filter and to not allow other connections.

## Building the Project
1. Open a command prompt and navigate to the project directory.
2. Run `dotnet build` to build the project.

## Running the Project
1. Open a command prompt and navigate to the project directory.
2. Run `dotnet run` to start the application.

## Publishing the Project
1. Open a command prompt and navigate to the project directory.
2. Run `dotnet publish -c Release -r win-x64 --self-contained` to publish the project.
3. Navigate to the `bin\Release\net6.0\win-x64\publish` directory to find the executable file.
